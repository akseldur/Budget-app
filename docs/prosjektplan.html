Utgangspunkt

DNBs eget dashboard kategoriserer transaksjoner på hele beløpet, ikke på det du faktisk brukte pengene på. Målet er full kontroll med minimal vedlikeholdsbyrde — automatisk henting, fornuftige defaults, og mulighet til å splitte når det trengs.

Backend: FastAPI DB: PostgreSQL Bank: Enable Banking (PSD2, restricted mode) Fonddata: Yahoo Finance (nøkkelfri) Frontend: React Native (Expo) Valuta: NOK

Status akkurat nå

Enable Banking sandbox-applikasjon er registrert og verifisert, og hele DNB-samtykkeflyten (auth → sesjon → saldo → transaksjoner) er testet ende-til-ende mot Mock ASPSP siden DNB ikke finnes i sandbox — bytter til ekte DNB i production/restricted mode senere. Kategoriserings- og prognoselogikken er skrevet og testet (12 grønne tester). Fondskurs hentes live fra Yahoo Finance. Syv UI-skjermer er designet som statisk mockup. Alt er pushet til GitHub.

Maskinbegrensning: denne økten kjørte på en arbeidsgiver-forvaltet Windows-maskin uten admin-rettigheter — ingen Docker, PostgreSQL, WSL eller Node.js kunne installeres. Alt som er bygget her er derfor ren logikk uten databaseavhengighet. Database, faktisk React Native-kode og sammenkobling av alt venter til du er på egen maskin.

Nøkkellogikk

Default-splitting

Når en transaksjon hentes fra banken opprettes automatisk én transaction_split-rad med hele beløpet, kategorisert via regelmotoren (eller "Ukategorisert"). Å splitte betyr å erstatte den ene raden med flere — appen skal aldri kreve manuell splitting for det normale tilfellet.

CHECK: SUM(splits.amount WHERE transaction_id = X) = transactions.amount

Prognose og varsel

Lineær fremskrivning fra hittil-forbruk, per kategori (inkl. underkategorier):

projected = spent_so_far × (days_in_month / days_elapsed)

Terskler foreslått som utgangspunkt, juster fritt per kategori:

Grønn projected < 80 % av budsjett   Gul 80–100 %   Rød projected > budsjett

Neste konkrete steg

Når du er tilbake på byggemaskinen (med Docker/Node tilgjengelig):

  1. Klon repoet — git clone https://github.com/akseldur/Budget-app.git, følg README for oppsett.
  2. Postgres + migrasjoner — docker compose up -d, deretter SQLAlchemy-modeller og første Alembic-migrasjon for skjemaet over.
  3. Koble sammen bank-flyten — lagre hentede transaksjoner i databasen, kjør dem gjennom regelmotoren automatisk.
  4. Ny production-app i Enable Banking — aktiver restricted mode, koble til ekte DNB-kontoer.
  5. React Native (Expo)-prosjekt — bygg skjermene fra mockupen mot det ekte API-et.
